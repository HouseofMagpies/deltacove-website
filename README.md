# DeltaCove website · version 3.1

Static front page plus **Musings & Views**, ready for GitHub Pages. No blog subscription, CMS, JavaScript framework, third-party font or build dependency. The two build scripts use Python's standard library.

## Publish on GitHub

1. Upload the contents of this folder to the root of your repository, including `.github/workflows/pages.yml`.
2. Use the `main` branch (or change the branch in the workflow).
3. In **Settings → Pages → Source**, select **GitHub Actions**.
4. Commit a change or run **Actions → Publish DeltaCove → Run workflow**.

The workflow builds the articles, stages only public pages and assets, then publishes. Markdown sources, templates and draft posts are excluded from the published output. Drafts committed to a public repository can still be read in that repository.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

No repository, deployment, domain or DNS settings have been changed for you.

## Add or edit an article

1. Copy `templates/post-template.md` into `posts/`, giving it a lowercase filename with hyphens, e.g. `what-makes-an-agent-useful.md`.
2. Edit its `title`, `date` (YYYY-MM-DD), `author` and `summary` in the opening metadata block.
3. Write below the closing `---`.
4. Set `draft: false` when ready. Commit the file in GitHub's editor.

GitHub automatically rebuilds and publishes after the commit. The date **inside the Markdown file** controls latest-to-oldest order, not the filename. Tied dates sort by filename for consistency. A malformed date stops the build with a message identifying the article. Drafts are skipped. A future date is not a scheduler: mark the post as a draft until ready.

Supported Markdown: paragraphs, headings, **bold**, *italics*, links, simple bullet/numbered lists, quotes, fenced code blocks and horizontal rules. Complex tables, nested lists, images, raw HTML and plugins are not supported in this small first version. Raw HTML is escaped.

`posts/why-connections-matter.md` is an editable opening article drafted from your page brief, included for review. Remove it or change `draft` to `true` if you prefer an empty launch collection.

## Preview locally

Open `index.html` to browse the home page and generated Musings pages. After editing articles, run:

```
python3 scripts/build_musings.py
```

The checked-in `musings/` pages let you review without running a server. They are regenerated by GitHub on publication. Edit the Markdown sources, not generated article HTML.
